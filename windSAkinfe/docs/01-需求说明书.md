# windSAkinfe 功能需求说明书

> 版本 v1.0 · 2026-11-08
> 文档状态：已冻结（作为编码基线）
> 适用平台：Windows / Linux / macOS

---

## 1. 产品定位

`windSAkinfe`（Swiss Army Knife for Files）是一个**单文件、零运行时、无外部程序依赖**的命令行批量文件工具箱。

一句话概括目标：**把「选中一批文件 → 按规律批量收拾它们」这件事，做成一条命令。**

典型使用者是在终端里干活的开发者、资料整理者、批量处理素材的人。

### 1.1 设计红线（硬约束）

| 编号 | 约束 | 说明 |
|---|---|---|
| C-1 | **算法全部自研** | 压缩、解压、哈希、编码、通配匹配、自然排序、正则匹配，均由本项目源码实现。不得链接 `zip`/`flate2`/`zstd`/`sha2`/`base64` 等现成实现库。 |
| C-2 | **不调用外部程序** | 不得 `Command::new("7z")`、不得调用 `tar`/`gzip`/`unrar`。目标机不需要安装任何压缩软件。 |
| C-3 | **唯一第三方依赖是 CLI 解析** | `clap` 仅做参数解析与帮助生成，不承担任何算法职责。除此之外零依赖。 |
| C-4 | **破坏性操作必须可预演** | 删除/移动/重命名/解压覆盖：默认在执行前打印计划；`--dry-run` 只打印不执行。 |
| C-5 | **不静默覆盖** | 目标已存在时默认跳过并告警，覆盖必须显式 `--force`。 |
| C-6 | **单文件分发** | 静态链接运行时，release 产物为单个可执行文件，体积目标 < 3 MB。 |

### 1.2 明确的不做（能力边界，必须对用户可见）

| 项目 | 结论 | 原因（事实） |
|---|---|---|
| **创建 RAR 压缩包** | ❌ 不支持 | RAR 的压缩算法（含 PPMd 变体与私有 LZ 变体）**规范从未公开**，只有 RARLAB 的闭源实现。任何"自研"在信息论上不可能——不是工作量问题。 |
| **解压 RAR 的压缩条目** | ⚠️ 仅 store（m0）条目 | RAR4/RAR5 容器结构可以自研解析（头部/CRC/分卷），但条目数据用 RAR 私有压缩方法时不具备解码规范。报错时明确提示"该条目使用 RAR 私有压缩方法 N，无公开规范，无法解码"。 |
| **分卷 RAR 重建** | ❌ 不支持 | 同上，且涉及跨卷上下文继承。 |
| **加密 7z（AES-256）** | ⚠️ 不支持 | 7z 加密是 AES+SHA256 迭代 KDF，可自研，但优先级低于核心功能，v1.0 不做；检测到 `kEncrypted` 时明确报错。 |
| **ZIP AES-256 加密** | ⚠️ 不支持 | v1.0 只做 ZipCrypto（传统 PKZIP 加密），AES 条目（method 99）报错提示。 |

> 以上限制全部通过**运行时明确报错**呈现，绝不静默产出错误数据。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 选择器（Selector） | 一段描述"哪些文件要处理"的表达式：位置参数 + `--include`/`--exclude`/`--depth`/`--type` |
| 源模式（Pattern） | 含通配符的字符串，用于匹配与捕获，如 `*.jpg`、`第*话` |
| 目标模板（Template） | 含占位符的重命名目标，如 `%03d-%*.jpg` |
| 捕获组（Capture） | 源模式中第 N 个 `*` 所匹配到的子串，在模板中用第 N 个 `*` 引用 |
| 执行计划（Plan） | 一批 (源 → 目标) 动作的完全展开列表，dry-run 输出的就是它 |
| 条目（Entry） | 压缩包内的单个成员（文件或目录） |

## 3. 全局约定

### 3.1 命令总览

```
windSAkinfe <命令> [参数...]

文件操作
  rm        批量删除（可选进回收站）
  cp        批量复制
  mv        批量移动 / 重命名（同目录即改名）
  rn        批量重命名（模板驱动，带序号与捕获回填）
  touch     批量改时间戳 / 批量建空文件
  link      批量建符号链接 / 硬链接

查找与观测
  find      按名称/类型/大小/时间查找
  stat      查看文件详细信息
  tree      目录树 + 体积统计
  wc        批量统计行/词/字节
  dedup     重复文件查找（大小 → 哈希 两级）

压缩
  pack      打包压缩（zip / 7z / tar / gz / xz）
  unpack    解压（zip / 7z / tar / gz / xz / rar 只读）
  split     大文件分卷
  join      分卷合并

编码与校验
  b64       Base64 编码 / 解码
  hash      计算 MD5 / SHA / SHA3 / BLAKE2 / BLAKE3 / CRC

文本
  replace   批量文件内容替换（支持精简正则）

其他
  cfg       查看/修改默认配置
```

### 3.2 全局选项（所有命令通用）

| 选项 | 默认 | 行为 |
|---|---|---|
| `-n, --dry-run` | 关 | 只打印执行计划，不做任何磁盘写入 |
| `-y, --yes` | 关 | 跳过交互确认 |
| `-f, --force` | 关 | 允许覆盖已存在目标 |
| `-q, --quiet` | 关 | 只输出结果与错误，不输出进度 |
| `--json` | 关 | 结构化输出到 stdout（进度与日志走 stderr） |
| `-j, --jobs <N>` | CPU 核数 | 并行度（复制/哈希/压缩条目级并行） |
| `--sort <by>` | `name` | `name`（自然序）/`size`/`mtime`/`none` |
| `--stdin-list` | 关 | 从 stdin 逐行读路径（配合 `find` 管道） |

### 3.3 退出码

| 码 | 含义 |
|---|---|
| 0 | 全部成功 |
| 1 | 部分失败（有成功也有失败，详情见 stderr 汇总） |
| 2 | 用法错误（参数非法、模式语法错） |
| 3 | 内部错误（IO 异常、数据损坏） |
| 4 | 被安全护栏拒绝（危险路径、未确认） |
| 5 | 能力不支持（如"创建 RAR"、"RAR 私有压缩方法"） |

### 3.4 确认协议

- 破坏性命令（`rm`/`mv` 覆盖/`unpack` 覆盖/`replace` 写回）在**首次执行前**打印计划摘要（N 个对象、总字节数、前 5 条明细），并要求输入 `y` 确认。
- `stdin` 非 TTY 且未给 `-y` → 直接以退出码 4 拒绝（防止脚本里误删）。
- `--yes` 等价于确认。

### 3.5 路径安全护栏（不可绕过，除 `--i-know-what-im-doing`）

以下目标一律拒绝（退出码 4）：

1. 盘符根 / 分区根（`C:\`、`/`）
2. 当前工作目录本身
3. 用户主目录本身及其一、二级父目录（如 `C:\Users\me`、`C:\Users`、`C:\`）
4. 系统目录（`C:\Windows`、`/usr`、`/etc`、`/System`、`/Library`）
5. `rm` 展开后对象数 > 1000 且未指定 `--include` 过滤器

## 4. 选择器与命名规律（所有命令的基础，必须先定义）

### 4.1 源模式语法（Pattern）

| 记号 | 语义 |
|---|---|
| `*` | 匹配任意长度子串（**不跨越路径分隔符**），且**产生一个捕获组** |
| `**` | 跨目录匹配任意层路径（不产生捕获组） |
| `?` | 匹配单个字符（不捕获） |
| `[abc]` | 字符集（不捕获） |
| `[a-z]` | 字符区间 |
| `[!a-z]` / `[^a-z]` | 取反字符集 |
| `{a,b,c}` | 备选分支（可嵌套一层） |
| `\*` `\?` `\%` | 转义为字面字符 |

匹配规则：

1. **大小写**：Windows 默认不敏感，`--case-sensitive` 可强制敏感；Linux/macOS 默认敏感。
2. **隐式全匹配**：`*.txt` 等价于 `*.txt`（锚定首尾），不需要写成 `^*\.txt$`。
3. **目录名也参与匹配**：`--type dir` 时可对目录名用模式。
4. **捕获编号**：从左到右第 N 个 `*` 为第 N 组，`{a,b}` 与 `?`/`[]` 不参与编号。

### 4.2 目标模板语法（Template）

#### 4.2.1 捕获回填

模板中的第 N 个 `*` 被替换为源模式第 N 个捕获组；若捕获数不足，该 `*` 原样保留并告警（不静默丢字符）。

```
源模式: 第*话-*.jpg
目标模板: [%03d]*.jpg
文件: 第03话-封面.jpg  →  捕获1=03, 捕获2=封面
结果: [001]03.jpg          ← 模板第1个*回填捕获1
```

#### 4.2.2 `%` 占位符

| 占位符 | 含义 | 示例 |
|---|---|---|
| `%d` | 自增序号（`--start`，默认 1；`--step` 默认 1） | `1,2,3` |
| `%Nd` | 定宽 N 位、左补零的序号（N = 1..9） | `%3d` → `001` |
| `%c` / `%Nc` | 字母序号 a,b,…,z,aa,ab（Excel 列式） | `%2c` → `aa` |
| `%s` | 原主名（不含扩展名） | `photo` |
| `%e` | 原扩展名（不含点，保留原大小写） | `JPG` |
| `%f` | 原文件名（含扩展名） | `photo.JPG` |
| `%p` | 原父目录名 | `素材` |
| `%P` | 相对选择根的父路径（用 `/` 分隔） | `2024/01` |
| `%m` | 修改日期 `YYYYMMDD` | `20240131` |
| `%H` `%M` `%S` | 修改时刻 时/分/秒（两位） | `09` |
| `%i` | 文件字节数 | `1048576` |
| `%t` | 执行开始时刻 `YYYYMMDD-HHMMSS` | `20261108-204312` |
| `%u` | 6 位随机 hex（冲突时自动重试） | `a3f19c` |
| `%%` | 字面 `%` | `%` |

#### 4.2.3 目标路径规则

1. 模板中若含 `/` 或 `\`，视为**相对路径**（相对"目标根目录"，默认取被选文件的父目录）。
2. 模板不含路径分隔符 → 只改文件名，仍留在原目录。
3. 最终扩展名若被模板明确写出（如 `.jpg`），则采用模板的；若模板无扩展名，则**保留原扩展名**（除非 `--no-ext-keep`）。
4. 结果与源相同（no-op）→ 跳过并计数为 `unchanged`。

### 4.3 排序

默认 `--sort name` 使用**自然排序**：把字符串切分为「非数字段 / 数字段」，数字段按数值比较。

```
img2.jpg  <  img10.jpg        （数值比较，非字典序）
第2卷      <  第10卷
```

### 4.4 预览

`rn`/`mv`/`cp` 均支持 `-n`，输出格式固定为：

```
[001] 源 → 目标
[002] 源 → 目标
...
合计 42 项，其中 3 项目标已存在（已跳过），1 项无变化
```

## 5. 功能需求

### F1 删除 `rm`

**输入**：路径列表（文件/目录/通配符/模式）。

**行为**：

1. 目标展开：目录默认递归；`--no-recursive` 只删空目录；`--depth N` 限制层数。
2. `--dirs-only` / `--files-only` 过滤。
3. 删除顺序：先删子项后删父目录（后序遍历），避免父目录先删导致子项失败。
4. `--trash` 走系统回收站（Windows 回收站 / macOS 废纸篓 / Linux `~/.local/share/Trash` 语义），`--trash` 与 `--force` 互斥。
5. 失败项不中断后续（收集后汇总），退出码 1。
6. 只读文件：Windows 下自动清只读位后重试（`--keep-readonly` 可关）。

**验收**：

- 删 1000 个嵌套文件，全部消失，退出码 0，耗时 < 3 s。
- 指向 `C:\` 或 `$HOME` 时退出码 4，不产出任何删除。
- `-n` 下磁盘零变化。

### F2 复制 `cp`

**行为**：

1. 目录递归复制，保留目录结构；`--flat` 拍平到同一目录。
2. 冲突策略：`--on-conflict skip|overwrite|rename|newer|ask`，默认 `skip`。
3. `--rename` 冲突时自动加 ` (1)`、` (2)` 后缀（仿资源管理器）。
4. 保留元数据：mtime 必保留；`--preserve-perms` 额外保留权限位。
5. 符号链接：默认跟随（复制目标内容）；`--copy-links` 复制链接本身。
6. 空间检查：目标卷剩余空间 < 总字节数 → 报错退出（退出码 3），不开始复制。
7. 同卷大文件优先 `copy_file_range`/`CopyFileEx` 快路径，失败回退普通读写。

**验收**：

- 复制 1 GB 单文件，内容 SHA256 与源一致。
- 目标已存在且默认策略下，源不被覆盖、目标 mtime 不变。

### F3 移动 `mv`

**行为**：

1. 同卷 → 原子 rename；跨卷 → 复制 + 校验大小 + 删除源（先复制成功才删）。
2. 冲突策略同 F2。
3. 目标在源内部（目录移动到自己的子目录）→ 直接拒绝（退出码 2），防止无限递归。
4. 批量移动时若中途失败，已完成项保留，未完成项列出，退出码 1。

**验收**：

- 跨卷移动 500 MB 文件后源消失、目标 SHA256 一致。
- `mv dir dir/sub` 被拒绝且磁盘无变化。

### F4 重命名 `rn`

**行为**：

1. 只改名字，不跨目录（跨目录请用 `mv`）；`--template` 必填。
2. 支持 §4.2 全部占位符与 `*` 捕获回填。
3. **两阶段执行**：先把所有源改到临时名（`.wsak_tmp_<pid>_<seq>`），再改成最终名。这样 `a→b, b→c` 这类链式改名不会互相踩踏。
4. 冲突：目标已存在 → 默认跳过并告警；`--force` 覆盖；`--on-conflict rename` 自动加序号。
5. 目录重命名支持；目录内后代不受影响（不需要改内容路径）。
6. `--number-mode`：`seq`（全局连续，默认）/ `per-dir`（每个目录重新从 start 计数）。

**验收**：

- 对 20 个 `IMG_0001.JPG` 执行 `--template "%3d.jpg"`，得到 `001.jpg … 020.jpg`，无临时文件残留。
- 链式改名 `a→b(已有), b→c` 场景不丢文件。

### F5 时间戳 `touch`

- `-c` 不存在不创建；`-m`/`-a` 只改 mtime/atime；`-t YYYYMMDDHHMM[.SS]` 指定时间；默认当前时间。
- `--pattern` 可批量套用同一时间。

### F6 链接 `link`

- `--symbolic`（默认）/ `--hard`；Windows 下 hard link 用 `CreateHardLinkW` 语义（`std::fs::hard_link`），symbolic 用文件/目录分别处理。
- 已存在目标：默认跳过，`--force` 删除后重建。

### F7 查找 `find`

**过滤维度**（可组合，AND 关系）：

| 选项 | 说明 |
|---|---|
| 位置参数 | 根目录，可多个 |
| `-p, --pattern` | 名称模式（§4.1） |
| `-t, --type` | `file` / `dir` / `link` / `empty` |
| `--min-size` / `--max-size` | 支持 `10K` `5M` `2G`（1024 进制） |
| `--newer` / `--older` | `7d` / `24h` / `2024-01-01` |
| `--depth` | 最大深度 |
| `--include` / `--exclude` | 路径级模式过滤 |

**输出**：默认每行一个路径（便于管道）；`--long` 输出大小+时间；`--json` 输出数组。

### F8 详情 `stat`

输出：名称、类型、绝对路径、大小（字节 + 人类可读）、创建/修改/访问时间、只读位、符号链接目标、所属卷剩余空间；`--hash` 追加哈希；`--json`。

### F9 目录树 `tree`

- `--depth N`（默认 3）、`--dirs-only`、`--sort size`。
- 每个节点显示体积；目录尾部显示合计与"子项数"。
- `--no-size` 跳过体积统计（大目录快很多）。

### F10 统计 `wc`

- 默认输出「行 词 字节 路径」；`--chars` 加字符数（UTF-8 码点）；`--total` 汇总行。
- 二进制文件（前 8 KB 含 NUL）自动跳过并告警，`--binary` 强制统计。

### F11 去重 `dedup`

1. 按大小分组，仅保留 ≥ 2 个的组。
2. 组内按「前 4 KB + 后 4 KB」哈希再筛。
3. 全文件哈希确认（分块流式，不整读内存）。
4. 输出重复组；`--delete dup|keep-first` 执行清理（默认只报告）。
5. `--hardlink` 用硬链接替代删除（省空间且保留路径）。

### F12 打包 `pack`

**支持格式**：`zip`、`7z`、`tar`、`gz`、`xz`；由 `-o` 扩展名推断，`-f` 可强制。

| 选项 | 说明 |
|---|---|
| `-o, --output` | 输出文件名；`%d`/`%t` 等占位符可用 |
| `-l, --level` | 0=仅存储，1..9 压缩级别 |
| `-p, --password` | ZipCrypto（zip）/ 不支持（7z、rar，见 §1.2） |
| `--split <size>` | 分卷大小（如 `100M`），仅 zip/7z 支持 |
| `--root <dir>` | 归档内根路径映射 |
| `--exclude` | 打包排除模式 |

**行为**：

1. 归档内路径统一用 `/`，不写盘符，剥离前导 `/`（防 Zip Slip）。
2. 空目录条目保留（zip/7z 支持）。
3. 进度：条目级 + 字节级；`--json` 时输出汇总对象。
4. 输入体积为 0 或只有空目录 → 正常产出空归档，不报错。

**验收**：

- 用自研实现产出 zip，能被 Windows 资源管理器、`C:\Program Files\7-Zip\7z.exe` 双向识别并正确解压（**互操作性验证**）。
- 反向：7-Zip 压出的 zip/7z 能被本工具解开且 SHA256 一致。

### F13 解压 `unpack`

- 支持 `zip` / `7z` / `tar` / `gz` / `xz` / `rar`（只读 store）。
- `-o` 目标目录（默认当前目录下的 `<包名>`）；`--flat` 拍平；`--include` 只解匹配条目。
- **Zip Slip 防护**：任何条目路径归一化后若逃出目标目录 → 拒绝该条目并告警。
- 覆盖：默认跳过已存在，`--force` 覆盖，`--on-conflict rename` 加序号。
- 保留条目 mtime。
- 损坏检测：CRC32 校验失败 → 该条目报错，退出码 1（不静默产出坏文件）。
- 加密：ZipCrypto 用 `-p` 解密；RAR 加密 / ZIP AES → 退出码 5 并说明原因。

### F14 分卷 `split` / 合并 `join`

- `split -s 100M big.bin` → `big.bin.001`、`big.bin.002`…（默认 3 位序号，`--digits` 可调）。
- `join big.bin.001` → 自动按序号拼接；`-o` 指定输出；缺号/序号断裂 → 报错。
- 流式处理，内存占用 ≤ 8 MB，支持 GB 级文件。

### F15 Base64 `b64`

| 选项 | 说明 |
|---|---|
| `-d, --decode` | 解码模式 |
| `-u, --url-safe` | `-_` 替代 `+/` |
| `--no-pad` | 省略 `=` 填充（解码时自动容忍） |
| `-o, --output` | 输出文件（默认 stdout） |
| `--wrap <N>` | 编码输出每 N 列换行（默认 0 = 不换行） |
| `--check` | 解码前严格校验字符集与长度 |

- 输入 `-` 表示 stdin；二进制安全；流式处理（每 48 KB 一块），大文件不爆内存。
- 解码时容忍空白字符（`\r\n\t 空格`）；非法字符 → 报错（退出码 3）并给出首个非法位置。

**验收**：

- 对 0..255 全部字节做往返编解码，结果与源逐字节相等。
- RFC 4648 测试向量全部通过。

### F16 哈希 `hash`

**支持算法**（全部自研）：`md5`、`sha1`、`sha224`、`sha256`、`sha384`、`sha512`、`sha3-224`、`sha3-256`、`sha3-384`、`sha3-512`、`blake2b`、`blake2s`、`blake3`、`crc32`、`crc64`。

| 选项 | 说明 |
|---|---|
| `-a, --algo` | 可逗号分隔多算法：`sha256,md5` |
| `-c, --check <file>` | 校验清单（`hash 值  路径` 或 `路径  值`），自动识别 |
| `--write <file>` | 生成校验清单（`sha256sum` 兼容格式） |
| `--upper` | 大写输出 |
| `--base64` | Base64 输出摘要（openssl 风格） |

- 大文件流式（64 KB 块），不整读；`-j` 并行多文件。
- 校验结果：`OK` / `FAILED` / `MISSING`，任一 FAILED → 退出码 1。

**验收**（必须逐条对齐公开标准测试向量）：

- MD5：`"" → d41d8cd98f00b204e9800998ecf8427e`，`"abc" → 900150983cd24fb0d6963f7d28e17f72`
- SHA1：`"abc" → a9993e364706816aba3e25717850c26c9cd0d89d`
- SHA256：`"abc" → ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`
- SHA512：`"abc" → ddaf35a193617aba...`
- SHA3-256：`"abc" → 3a985da74fe225b2045c172d6bd390bd855f086e3e9d525b46bfe24511431532`
- BLAKE2b-512：`"abc" → ba80a53f981c4d0d6a2797b69f12f6e94c212f14685ac4b74b12bb6fdbffa2d1...`
- BLAKE3：`"abc" → 6437b3ac38465133ffb63b75273a8db548c558465d79db03fd359c6cd5bd9d85`
- CRC32：`"123456789" → cbf43926`

### F17 文本替换 `replace`

- `-p, --pattern`：支持精简正则（见 §7.2）或 `--literal` 字面匹配。
- `-r, --replacement`：支持 `$1..$9` 与 `$0`、`$$`。
- 默认只报告匹配数量（`--dry-run` 语义），`--write` 才落盘。
- 保留原换行风格（CRLF/LF 原样）；`--encoding` 仅支持 UTF-8 与 GB18030 探测（同 windMusic 做法：UTF-8 → GB18030 → Latin-1 回退）。
- 二进制文件（含 NUL）默认跳过。

### F18 配置 `cfg`

- 配置文件：`%APPDATA%\windSAkinfe\config.toml`（Windows）/ `~/.config/windSAkinfe/config.toml`。
- 可配置项：默认 `--jobs`、默认冲突策略、确认阈值（对象数/字节数）、`--trash` 默认开关、是否彩色输出。
- `cfg list` / `cfg set key value` / `cfg path`。

## 6. 算法自研清单（对应 C-1）

| 模块 | 自研内容 | 关键规格 |
|---|---|---|
| DEFLATE | inflate 解码 + deflate 编码（LZ77 + 动态 Huffman） | RFC 1951；窗口 32 KB；匹配长度 3..258 |
| ZIP | 本地头/中央目录/EOCD/Zip64 + CRC32 + ZipCrypto | PKWARE APPNOTE；Zip64 仅读 |
| LZMA | Range coder（编码+解码）+ LZMA1 解码 + LZMA1 编码（hash-chain 惰性匹配） | lc=3 lp=0 pb=2；字典 64 MB 上限 |
| LZMA2 | chunk 封装（控制字节、状态重置、属性重设） | xz 与 7z 共用 |
| 7Z | 容器头编解码（kHeader/kMainStreamsInfo/kFilesInfo/Folder/Coder 链）、CRC 校验 | 7z 格式 0.4；编码用 LZMA2 单 Folder |
| TAR | ustar 头读写 | POSIX ustar；长路径用 GNU `L` 扩展 |
| GZ | gzip 头/尾（FEXTRA 跳过、CRC32、ISIZE） | RFC 1952 |
| XZ | 流头/块头/索引/流尾 + LZMA2 | xz 格式 1.0.4；CRC64 校验 |
| RAR | **只读**容器：RAR4/RAR5 头、CRC、store 条目 | 见 §1.2 限制说明 |
| 哈希 | MD5 / SHA1 / SHA2 全族 / SHA3 全族 / BLAKE2b / BLAKE2s / BLAKE3 / CRC32 / CRC64 | FIPS 180-4、FIPS 202、RFC 7693、BLAKE3 规范 |
| Base64 | 标准 + URL-safe + 无填充 + 流式 | RFC 4648 |
| 通配匹配 | `*` `**` `?` `[]` `{}` + 捕获 + 反向引用回填 | 见 §4.1 |
| 自然排序 | 数字感知比较 | 见 §4.3 |
| 精简正则 | 回溯引擎：`.` `*` `+` `?` `[]` `()` `\|` `^$` `\d\w\s\D\W\S` `{n,m}` | 无后向引用 |

## 7. 非功能需求

### 7.1 性能

| 场景 | 目标 |
|---|---|
| 遍历 10 万文件并匹配模式 | < 2 s（热缓存） |
| 复制 1 GB | ≥ 150 MB/s（同卷） |
| SHA256 单文件 | ≥ 300 MB/s |
| deflate 压缩 level 6 | ≥ 20 MB/s |
| LZMA 压缩 level 6 | ≥ 2 MB/s |
| 启动到输出帮助 | < 30 ms |

### 7.2 健壮性

- 任何单文件失败不得中断整批；失败汇总后以退出码 1 结束。
- 中断（Ctrl-C）：已完成项不回滚，临时文件在下次启动时清理（`.wsak_tmp_*` 前缀扫描）。
- 所有路径操作用 `OsStr` 全程传递，非 UTF-8 文件名不丢失（Windows 用 `encode_wide`）。
- 输出宽度自适应终端（`COLUMNS` 或系统查询），非 TTY 时不带 ANSI 颜色。

### 7.3 可分发性

- release 单文件 < 3 MB，无动态库依赖（除系统 CRT）。
- 不写注册表、不改系统设置（`cfg` 仅写用户配置目录）。
