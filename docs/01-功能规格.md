# windFileManger 功能规格（v1）

> 依据对 **NanoFile 1.0.81.0**（深圳晓得智能，Microsoft Store MSIX 包
> `Xiaode.NanoFile_1.0.81.0_x64__zwe0ez2b5t554`）的逆向分析，用 Rust + Slint 复刻其核心功能的本地文件管理器。
> **目录导航不使用树形结构**：侧边栏平铺 + 面包屑 + 当前目录平面列表。

---

## 1. 原版逆向结论（证据）

技术栈（从 MSIX 包内容实证）：

| 项 | 结论 | 证据 |
|---|---|---|
| 框架 | Tauri 2 + WebView2/wry，前端 React + Vite 单页 | exe 内 `tauri`×322、`wry`、`WebView2` 字符串；内嵌 `assets/index-BN3SKPav.js`（brotli，解压 5.55 MB）+ `index-C6pU29I5.css` |
| 后端 | Rust，tokio 1.54.1，sqlx-sqlite 0.9.0 | PE 内嵌 crate 路径 `C:\Users\i-cgh\.cargo\registry\...\tokio-1.54.1\...`、`sqlx-sqlite-0.9.0` |
| 双进程 | NanoFile.exe（UI）+ service.exe（NTFS USN 索引服务） | 包内两 exe；字符串 `[Rust] Service USN`、`file_index.db`、`user_data.db` |
| Shell 集成 | Win11 现代右键菜单 COM 扩展 + ~300 扩展名文件关联 | AppxManifest.xml `desktop4:FileExplorerContextMenus`、`com:SurrogateServer`（Clsid 8E22C8DF-…）、14 组 `fileTypeAssociation` |
| 代码来源 | 开发机用户名 i-cgh，源码目录 `src\commands\{vault,file,applications,recycle_bin}`、`src\ntfs_dir.rs`、`src\mem_search\` | PE 内 `src\commands\vault\vault_auth.rs` 等路径字符串 |

原版功能全集（自 Tauri 命令注册表字符串提取，共 150+ 命令）：

1. **文件浏览**：多标签页（`create_window_with_tab`、标签拖拽）、三种视图（列表/宫格/画廊）、面包屑路径编辑、排序、智能分类文件夹
2. **文件操作**：复制/移动/删除/新建/重命名（`copy_items`/`move_items`/`delete_items`/`create_new_item`/`rename_item`）、粉碎删除（`shred_items`）、剪贴板集成（`write_files_to_clipboard`）
3. **回收站**：`get_recycle_bin_items`/`restore_recycle_bin_items`/`delete_recycle_bin_items`
4. **搜索**：实时搜索（`search_directory`、`cancel_all_searches`）+ 后台全盘索引（service.exe 走 **NTFS USN Journal**，SQLite `file_index.db`，内存索引 `build_mem_index`、`get_disk_index_status`、索引模式切换）
5. **目录统计**：`get_dir_stats`/`get_dir_stats_batch`（后台算文件夹体积，可 pause/resume/invalidate）
6. **压缩包**：`compress_items`/`extract_archive(s)`/`add_files_to_archive`
7. **预览**：文本/代码（内嵌 highlight.js）、图片查看、视频播放（外挂字幕 `find_and_read_subtitle`、歌词 `find_and_read_lyrics`）、PDF/Office 文档解析（`read_document_content`）、缩略图（`get_file_thumbnail`）
8. **应用程序管理**：`get_applications`/`uninstall_application`/设置默认打开方式（`get_associated_apps_for_ext`/`set_default_app_for_extension`）
9. **隐私保险箱**：Windows Hello + 密码（`set_privacy_password`/`verify_privacy_password`/`lock_privacy_vault`，`src\commands\vault\vault_auth.rs`）
10. **标签**：NTFS ADS 标签（`read_file_tags_ads`/`write_file_tags_ads`）+ 用户标签
11. **云盘**：OneDrive 云文件（`get_cloud_drives`/`download_cloud_file`/`set_cloud_pin_state`）
12. **磁盘**：`mount_disk_image`（ISO/VHD）、`eject_disk`、`get_wsl_distros`、`fetch_network_disks`、WPD 便携设备
13. **快捷方式**：`.lnk` 属性解析/改目标（`get_shortcut_property_info`/`resolve_shortcut_target`）
14. **收藏/最近**：favorites/recent paths + 应用使用统计
15. **商业化**：NanoFile Plus 订阅（`require_vip`/`purchase_subscription`，微软商店 IAP、7 天试用）

## 3. 非树形目录导航设计

- 侧边栏是**两段平铺列表**（快速访问 + 磁盘 + 收藏），无任何展开/折叠节点；
- 主区永远只显示**当前目录一层**内容；
- 上级/跳转全靠：面包屑（每段一个按钮）、侧边栏平铺项、Alt+↑。
- 与 NanoFile 一致：无目录树控件。

## 4. 架构

```
windFileManger/
├─ Cargo.toml            # slint 1.13.1, windows-sys, serde/toml, chrono
├─ build.rs              # slint-build + winresource(图标)
├─ ui/app.slint          # 全部 UI（单文件，全局 <Metrics>）
└─ src/
   ├─ main.rs            # 事件循环、全局状态、后台线程调度
   ├─ model.rs           # Entry/Tab/Sort/Category 数据结构与 Slint 模型桥
   ├─ fs.rs              # read_dir 快速列举（DirEntry::metadata 零 stat）、类型分类表
   ├─ ops.rs             # 新建/重命名/删除(回收站)/复制移动/剪贴板 CF_HDROP
   ├─ stats.rs           # 后台目录统计
   ├─ search.rs          # 后台递归搜索
   ├─ preview.rs         # 图片/文本预览
   └─ config.rs          # config.toml 读写
```

线程模型：IO 全部在 `std::thread`，结果经 `slint::Weak::upgrade_in_event_loop`/`invoke_from_event_loop` 回 UI；统计与搜索各带 `AtomicBool` 取消标志。

## 5. 关键实现约定（沿用项目记忆铁律）

- Windows 遍历只用 `DirEntry::metadata()`（复用 WIN32_FIND_DATA，**零额外 stat**），绝不用 `fs::symlink_metadata` 逐文件补查；
- `SHFileOperationW` 前剥离 `Path::canonicalize` 的 `\\?\` 前缀（返回 124 坑）；
- 双 NUL 结尾的宽字符路径列表（DROPFILES）；
- Slint 1.13：ComboBox 弹层只有 6 行、PopupWindow 内部属性外部不可读、`absolute-position` 是窗口坐标（含标题栏）；
- release：opt-level=3 + lto + codegen-units=1 + strip；长驻 GUI 不用 `panic="abort"`；
- clippy 零告警；`cargo test` 覆盖 fs 分类/排序/路径工具函数。

## 6. 验收标准

1. 浏览 C:\、D:\ 与含 10 万+ 文件目录不卡 UI（列举在后台线程）；
2. 删除进回收站、Explorer 与本程序剪贴板互通；
3. 面包屑每级可点、后退/前进栈正确；
4. 文件夹大小统计与递归搜索均可取消且不阻塞 UI；
5. 收藏夹与设置重启后保留；
6. `cargo test` 全绿、`cargo clippy` 零告警。
