# 会话状态持久化功能规格（03）

## 1. 目标

关闭 windFileManger 后再次打开（无命令行参数时），自动恢复到**最后一次关闭时的状态**：

1. 窗口尺寸与最大化状态
2. 标签页集合与每个标签的当前目录、激活标签

## 2. 非目标（明确排除）

- **窗口位置（x/y）不持久化**：winit 多显示器 / 多 DPI 环境下位置恢复易漂移出屏，收益低风险高。
- 标签的**历史栈**（后退/前进）不持久化，只恢复当前目录（历史栈序列化体积大且易失效）。
- 侧栏滚动位置、预览开关、搜索词等瞬态不持久化。

## 3. 配置结构变更（config.toml）

```toml
window_w = 1180.0      # 逻辑像素（已有字段，语义修正）
window_h = 760.0       # 逻辑像素
window_max = false     # 新增：退出时是否最大化
last_tabs = []         # 新增：每个标签的当前目录（按标签顺序）
active_tab = 0         # 新增：激活标签在 last_tabs 中的下标
```

- `serde(default)` 兜底，旧配置文件无需迁移。
- **尺寸语义修正**：旧代码保存 `window().size()`（物理像素）且启动从不应用——改为保存**逻辑像素**（`size.to_logical(scale_factor)`），启动时 `window().set_size(LogicalSize)` 应用。
- **最大化时尺寸保护**：`window_max == true` 时退出**不覆盖** `window_w/h`（最大化尺寸不是合理还原尺寸），下次还原时直接按保存的 w/h 恢复再置最大化。

## 4. 启动恢复优先级

```
命令行参数 dir（显式指定）  →  单标签打开该目录，不恢复会话
无参数 且 last_tabs 非空    →  逐项校验 is_dir（失效项丢弃），恢复多标签 + active_tab
                              （active_tab 越界则取最后标签；全部失效 → 回落 USERPROFILE）
其余                        →  USERPROFILE（现状）
```

## 5. 行为细节

1. **应用时机**：`app.show()` 之后、`run()` 之前 `set_size` + `set_maximized`（winit 窗口已创建，避免 run 前设置丢失）。
2. **保存时机**：`app.run()` 返回后（正常关闭路径）。`taskkill` 强杀不保存——可接受（与主流软件一致）。
3. Tab id 重建：恢复的标签按序分配 id 1..n，`next_tab_id = n+1`，`active` 映射回对应 id。
4. 关闭全部标签自动新建 C:\ 的现有行为保持不变（退出保存的是真实集合）。
