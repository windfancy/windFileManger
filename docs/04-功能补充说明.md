# 功能补充说明（04）：UI 修复与新入口（2026-11-14 四轮）

> 本轮为「缺陷修复 + 交互补充」混合批次，先修回归再补功能。

## 1. 窗口缩放回归修复（严重）

**现象**：窗口无法拖拽调整大小、最大化按钮禁用。

**根因**：Window 显式 `width/height` + 裸弹性元素（无显式 min 约束）时，Slint 布局约束
min==max，`i-slint-backend-winit` 的 `window_is_resizable()` 返回 false，创建窗口时剥掉
`WS_THICKFRAME | WS_MAXIMIZEBOX`。实测最小复现确认；给弹性元素加 min 约束在复杂结构下
不可靠（显式 `width:100%` 绑定会切断约束传播）。

**修复**：`force_resizable()`（main.rs）——show 后用 `FindWindowW + SetWindowLongW`
补回 style，`SWP_FRAMECHANGED` 刷新；`slint::Timer::single_shot(800ms)` 二次强制
（winit 首帧/首次 apply_constraints 会再剥一次，约束静态后即稳定）。

## 3. 新入口

| 功能 | 入口 | 实现 |
|---|---|---|
| 应用程序 | 侧栏快速访问 | `shell:AppsFolder` → explorer |
| 回收站 | 侧栏快速访问 | `shell:RecycleBinFolder` → explorer |
| 在终端打开 | 条目右键 (18) | `cmd /k cd /d "<dir>"`（文件用父目录） |
| 查看路径 | 条目右键 (19) | 对话框（mode6）显示完整路径 + 复制按钮 |
| 收藏此文件夹 | 条目右键 (20) | 目录加入 favorites，重复提示 |
| 远程访问 | 侧栏段头 ＋ → 对话框（mode7） | 地址自动识别类型（`RemoteItem::infer`），持久化 `config.remotes` |

**远程访问类型边界**（第一版）：
- **SMB** `\\host\share` → 应用内导航（std::fs 原生支持 UNC；仅 `\\host` 无共享名会被安全拒绝）
- **FTP** `ftp(s)://…` / **WebDAV** `http(s)://…` → `ShellExecuteW` 系统打开
- **DLNA** `dlna://…` → 保存条目，系统无默认处理器时会提示打开失败
